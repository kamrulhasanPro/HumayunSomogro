# হুমায়ূন সমগ্র — অফলাইন রিডার (Android)

২১১টি বই, ২৪৯৮টি অধ্যায় — সব টেক্সট অ্যাপের ভেতরেই আছে, ইন্টারনেট লাগে না।

## APK বানানোর দুইটি উপায়

### ক) Android Studio (সবচেয়ে সহজ)
1. Android Studio খুলে **Open** → এই ফোল্ডারটি বেছে নিন, Gradle sync শেষ হতে দিন।
2. **Build ▸ Build Bundle(s)/APK(s) ▸ Build APK(s)**
3. `app/build/outputs/apk/debug/app-debug.apk` ফোনে ইনস্টল করুন।

### খ) GitHub Actions (কম্পিউটারে কিছু ইনস্টল ছাড়াই)
1. GitHub-এ একটি নতুন (private) repo বানিয়ে এই ফোল্ডারের সব ফাইল আপলোড করুন (`.github` ফোল্ডারসহ)।
2. repo-র **Actions ▸ Build APK ▸ Run workflow**
3. কাজ শেষ হলে **Artifacts ▸ HumayunSomogro-apk** ডাউনলোড করে ফোনে ইনস্টল করুন।

## কোথায় কী
- `app/src/main/assets/www/` — পুরো অ্যাপ (HTML/CSS/JS) ও বইয়ের ডাটা (`data/bXXX.js`)
- `app/src/main/java/.../MainActivity.java` — WebView র‍্যাপার

## সংস্করণ ১.১ — যা ঠিক করা হয়েছে
- **হ্যাপটিক (কাঁপুনি) কাজ করত না** — `VIBRATE` পারমিশন ম্যানিফেস্টে ছিল না, ত্রুটিটা চুপচাপ গিলে ফেলা হতো। যোগ করা হয়েছে।
- **"পরের অধ্যায়" বোতাম চাপলে** পড়ার পাতার বার (immersive মোড) অযথা অন-অফ হয়ে যেত — ঠিক।
- **মেমরি**: খোলা প্রতিটি বই মেমরিতে জমে থাকত (সব বই মিলে ~৭০MB টেক্সট)। এখন শুধু চলতি + সাম্প্রতিক বই থাকে।
- বই লোড ব্যর্থ হলে অব্যবহৃত Promise error ও অপেক্ষমাণ কলব্যাক আটকে থাকত — ঠিক।
- **ব্যাকআপ রিস্টোর** ভুল/ভাঙা ডাটা নিলে পরে অ্যাপ ক্র্যাশ করতে পারত — এখন যাচাই করে তবেই নেয়।
- UI-র বোতাম/লেবেলে লম্বা চাপে লেখা সিলেক্ট হয়ে যেত — এখন শুধু পড়ার লেখা ও ইনপুটে সিলেক্ট চলে।
- হোমে বইয়ের প্রিয়-চিহ্ন বদলালে তালিকা সঙ্গে সঙ্গে হালনাগাদ হয়।
- **নেটিভ**: ক্লিপবোর্ড/শেয়ার এখন UI থ্রেডে; WebView রেন্ডারার ক্র্যাশ করলে অ্যাপ বন্ধ না হয়ে পেজ পুনরায় লোড হয়; ব্যাকগ্রাউন্ডে যাওয়ার আগে পড়ার অবস্থান সেভ হয়; ফাইল-সিস্টেম অ্যাক্সেস বন্ধ (assets-এর কিছু বদলায়নি); বাইরের লিংক শুধু http/https/mailto খোলে; `onDestroy`-এ WebView পরিষ্কার হয়।
- GitHub Actions: টাইমআউট, ব্যর্থ হলে স্পষ্ট এরর, আর্টিফ্যাক্ট চেক যোগ।
